## 🛑 ملخص الأزمة التي استدعت هذه الخطة
الشاشات الحالية تعاني من:
1. **كراشات أخطاء قاتلة** تظهر للمستخدم (مثل كراش الشارت التفاعلي `CHART_GRID is not defined`).
2. **شاشات فارغة أو معلقة في تحميل دائم** (مثل شاشة `#prediction-tracking` التي تظل تعرض هياكل Skeleton خضراء للأبد ونسبة 0.0%).
3. **تشتت وزحمة تبويبات غير مبررة** داخل شاشة التوقعات `#recommendations`، ودفن خدمات مستقلة (مثل التقارير) داخلها.
4. **تكرار سخيف** (مثل وجود حاضنة الأسهم مرتين: كتاب داخل التوقعات وكشاشة مستقلة `#incubator`).
5. **شاشة رئيسية (Dashboard) غير منضبطة:** تخلط العملات المشفرة مع الأسهم المصرية وسبيكة الذهب في كارت واحد ("توقعات اليوم")، وتعتمد على سهم واحد فقط (`COMI`) لعرض ما يسمى "ضغط الجلسة".
6. **شاشات وهمية أو معقدة بلا فائدة للعميل** (مثل `smart-confluence` و `market-depth`).

## 📋 بنود التكليف التنفيذي (خطوة بخطوة بالمليمتر)

### 1. إصلاح كراش الشارت التفاعلي فوراً (`#trading-chart`)
- **الملفات المستهدفة:**
  - `src/modules/market-analysis/components/interactive-chart/types.ts`
  - `src/modules/market-analysis/components/interactive-chart/InteractiveChart.tsx`
- **وصف المشكلة:**
  ظهور شاشة بيضاء وكراش من خلال ErrorBoundary بالنص:
  `ReferenceError: CHART_GRID is not defined at y (8086...)`
- **سبب المشكلة:**
  الثابت `CHART_GRID` وُجد كـ `const` خاص داخل `types.ts` (سطر 149) دون `export`، وتم استخدامه في `InteractiveChart.tsx` دون عمل `import`.
- **التنفيذ الإلزامي:**
  1. في `types.ts`: تصدير جميع ثوابت الألوان:
     ```typescript
     export const CHART_BG = '#131722';
     export const CHART_GRID = '#363c4e';
     export const CHART_TEXT = '#d1d4dc';
     export const UP_COLOR = '#26a69a';
     export const DOWN_COLOR = '#ef5350';
     ```
  2. في `InteractiveChart.tsx`: استيراد `CHART_GRID`:
     ```typescript
     import { CHART_GRID } from './types';
     ```
- **الإثبات:** فتح الرابط `http://localhost:3000/#trading-chart` ورؤية الشموع والمؤشرات تعمل بسلاسة دون أي أخطاء في الـ Console.

### 2. إصلاح شاشة تتبع وسجل التوقعات (`#prediction-tracking`)
- **الملف المستهدف:**
  `src/modules/predictions/components/PredictionTrackingView.tsx` (السطور 395 إلى 410)
- **وصف المشكلة:**
  الشاشة تظهر 17 توقعاً معلقاً، ولكن جميع الكروت تعرض `0.0%`، والجدول معلق في حالة تحميل (Skeleton أخضر) دائم ولا تظهر به صفوف.
- **سبب المشكلة:**
  الـ API `/api/predictions/honest-tracking/list` يعيد كائناً يحتوي على المصفوفة في مفتاح `json.predictions`، بينما كود الفرونت في `fetchList` يتحقق حصراً من `json.data` (وهو `undefined`) فيفشل في تعيين `setPicks`!
- **التنفيذ الإلزامي:**
  في دالة `fetchList` (سطر 400):
  ```typescript
  const json = await res.json();
  const rawList = Array.isArray(json.predictions) 
    ? json.predictions 
    : (Array.isArray(json.data) ? json.data : []);
  if (json.success && Array.isArray(rawList)) {
    setPicks(rawList as TrackedPick[]);
  } else {
    setPicks([]);
  }
  ```
- **الإثبات:** فتح الرابط `http://localhost:3000/#prediction-tracking` ورؤية جدول الصفقات المكتملة والمعلقة مع أسعار الدخول ونسب الأرباح المحدثة فوراً.

### 3. تنظيف وترتيب شاشة التوقعات والفرص (`#recommendations`)
- **الملفات المستهدفة:**
  - `src/modules/market-analysis/components/MarketAnalysisView.tsx`
  - `src/modules/market-analysis/components/PersonaTab.tsx`
- **المشاكل الحالية:**
  1. الشاشة غارقة في التبويبات الفرعية التي تشتت العميل.
  2. وجود تبويب كامل للتقارير الصباحية واليومية مدفون تحت التوقعات، مما يضيع قيمته.
  3. تكرار تاب حاضنة الأسهم داخل شاشة التوقعات رغم وجود شاشة مستقلة لها.
- **التنفيذ الإلزامي:**
  1. **حذف تبويب التقارير من داخل شاشة التوقعات:** التقارير خدمة استخباراتية مستقلة لها مسارها الخاص في الرابط `#reports`، ولا يجوز إخفاؤها هنا.
  2. **حذف تاب حاضنة الأسهم من داخل التوقعات:** تثبيت الحاضنة في شاشتها المستقلة `#incubator` فقط لتجنب الازدواجية.
  3. **قفل التركيز داخل شاشة التوقعات على هدف واحد:**
     عرض صفقات التمركز والتصحيح الهادئ (**The Golden Dip**) ببيانات الدخول والوقف والهدف الحقيقي ونسبة $R/R \ge 2.0$.
  4. تفعيل مصفوفة التحذير الشفاف في أعلى الشاشة:  
     *"الاستراتيجية قائمة على التمركز السوينجي (2-14 يوماً) لاقتناص مناطق الدعم الهادئة؛ البيانات تتحدث كل 5 دقائق وليست للمضاربة اللحظية (Scalping)."*

### 4. إعادة هندسة شاشة لوحة التحكم الرئيسية (Dashboard Cleanup)
- **الملف المستهدف:**
  `src/modules/dashboard/components/DashboardView.tsx` ومكوناته
- **المشاكل الحالية:**
  1. **كارت "توقعات اليوم":** يخلط في نفس الصندوق الصغير سهم مصري (`COMI`) مع عملات رقمية (`BTC`, `ETH`) مع سبيكة ذهب (`GOLD`)! هذا كوكتيل غير احترافي يربك العميل.
  2. **كارت "تدفق المستثمرين":** يعرض بيانات تفصيلية للأجانب والعرب والمصريين حتى عند اختيار أسواق غير مصرية.
  3. **ويدجت "ضغط الجلسة":** يعرض سهم `COMI` بمفرده كأنه يمثل كل السوق!
- **التنفيذ الإلزامي:**
  1. **إعدام كارت الكوكتيل العشوائي:**
     - عند اختيار سوق مصر (`EGX`)، تعرض التوقعات أسهم مصرية فقط من صفقات الـ Golden Dip.
     - العملات الرقمية تذهب لقسمها الخاص فقط (`market=CRYPTO`).
  2. **بناء ويدجت مستقل ومركزي للذهب والعملات (The Sovereign Desk):**
     - يعرض: جرام 24، جرام 21، جرام 18، الجنيه الذهب، وسعر الصرف الرسمي والموازي.
     - ممنوع خلط أسهم أو كريبتو داخل ويدجت الذهب والعملات.
  3. **تقييد تدفق المستثمرين (مؤسسات/أفراد وأجانب/عرب/مصريين):**
     - يظهر حصراً عند اختيار البورصة المصرية (`market=EGX`)؛ وفي حالة اختيار سوق آخر يُخفى أو يظهر رسالة "البيانات غير متاحة لهذا السوق".
  4. **تطوير عرض ضغط الجلسة:**
     - عرض ضغط المؤشر العام (`EGX30 Cumulative Pressure`) أو خريطة حرارية لأعلى 10 أسهم، بدلاً من حصر الشاشة كلها في سهم واحد.

## 🚫 المحظورات الحديدية لفريق Alpha:
1. **ممنوع نهائياً حساب أي مؤشر فني أو سعر داخل ملفات `src/`:** الحسابات تأتي من البايثون فقط.
2. **ممنوع تخمين السعر اللحظي (No Fake Fallbacks):** لا يجوز استخدام سعر الدخول القديم أو الهدف أو مكرر الأرباح مكان السعر الحي. إذا لم يتوفر السعر يُعرض `--`.
3. **ممنوع إظهار توصية شراء لسهم كسر وقف خسارته:** أي صفقة فيها $\text{Stop} \ge \text{Current Price}$ تظهر فوراً كـ `🛑 كسر وقف` ويُعتم صفها.
4. **ممنوع Force Push على مستودع Git.**

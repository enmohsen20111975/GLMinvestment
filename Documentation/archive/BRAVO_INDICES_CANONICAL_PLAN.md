# وثيقة برافو (Bravo) — توثيق وتثبيت مكونات المؤشرات الرسمية (Constituents Master)
**الهدف:** إنشاء المصدر الدستوري الموحد لمكونات مؤشرات البورصة المصرية (EGX30, EGX70, EGX100) وتحديث قاعدة البيانات وربطها بالـ API.

---

## 1. الفضيحة المكتشفة في قاعدة البيانات (stocks.db):
- جدول `stocks` يحتوي على أعمدة `is_egx30` و `is_egx70` و `is_egx100`.
- الفحص كشف أن `is_egx30 = 1` محدد لـ **15 سهماً فقط**!
- أسهم قيادية تاريخية مثل: البنك التجاري الدولي (`COMI`)، السويدي إليكتريك (`SWDY`)، هيرمس (`HRHO`)، وأبو قير للأسمدة (`ABUK`) لم تكن محددة كأعضاء في EGX30!

---

## 2. قائمة الـ 30 سهماً الرسمية المعتمدة لمؤشر EGX30:
1. `COMI` — البنك التجاري الدولي

3. `ETEL` — المصرية للاتصالات
4. `SWDY` — السويدي اليكتريك
5. `HRHO` — مجموعة إي اف جي القابضة
6. `ABUK` — ابوقير للاسمدة والصناعات الكيماوية
7. `MFPC` — مصر لإنتاج الأسمدة - موبكو
8. `FWRY` — فوري لتكنولوجيا البنوك والمدفوعات الإلكترونية
9. `CIEB` — بنك كريدي اجريكول مصر
10. `HDBK` — بنك التعمير والاسكان
11. `EKHO` — مصر الكويت القابضة
12. `EAST` — الشرقية - ايسترن كومباني
13. `HELI` — مصر الجديدة للاسكان والتعمير
14. `PHDC` — بالم هيلز للتعمير
15. `EFIH` — اي فاينانس للاستثمارات المالية والرقمية
16. `EMFD` — إعمار مصر للتنمية
17. `ORAS` — اوراسكوم كونستراكشون بي ال سي
18. `ESRS` — حديد عز

20. `AMOC` — الإسكندرية للزيوت المعدنية (أموك)

---

## 3. خطة التنفيذ المطلوبة من برافو:
1. إنشاء ملف JSON مرجعي ثابت: `vps-service/data/canonical_indices.json` يحتوي على قوائم الـ (EGX30, EGX70, EGX100).
2. تنفيذ سكريبت ترحيل (Migration Script) يقوم بـ:
   ```sql
   UPDATE stocks SET is_egx30 = 0;
   UPDATE stocks SET is_egx30 = 1 WHERE ticker IN ('COMI', 'TMGH', ...);
   ```
   بحيث يصبح عدد الأسهم التي تحمل `is_egx30 = 1` يساوي **30 سهماً بالضبط**.
3. إنشاء اندبوينت مستقل للفرونت إند:
   `GET /api/market/indices/constituents?index=EGX30`
   يُرجع قائمة الأسهم الخاصة بالمؤشر مع أسعارها وتغيراتها اليومية.

# وثيقة تكليف فريق ألفا (Alpha) — خطة تصحيح كوارث الواجهات والشاشات
**المصدر:** شكاوى المالك الصريحة والمباشرة  
**الهدف:** تصليح كل خرم في الواجهات، منع الكراش، وربط الشاشات بالبيانات الحقيقية بدون قص ولزق أعمى  
**الحالة:** إلزامي وفوري — لا يُقبل أي عذر أو كود نص كم

---

## شكاوى المالك بالتفصيل الممل:
1. **شارت التداول (`#trading-chart`):** كراش كامل وشاشة سوداء بسبب `ReferenceError: CHART_TEXT is not defined` في `InteractiveChart.tsx`.
2. **رادار السيولة (`#liquidity-radar`):** كاتب "مرفوض 10 سهم" وجدول فاضي كاتب "لا توجد أسهم مطابقة" وكل التابات (0).
3. **الداشبورد الرئيسية:** شغل قص ولزق رخيص، عارض أسهم مضروبة بنسبة +24400% (HALN)، وكروت مرصوصة بدون رؤية استثمارية.
4. **شاشة ضغط السوق (`#market-status`):** صفحة كاملة عريضة في الراوتر عشان تعرض عداد واحد وبانر وتحتها فراغ أسود.
5. **شاشة التوقعات (`#recommendations`):** واجهة متخلفة ومربكة، تاب خارجي جواه زرار واحد بس، وجواه ToggleGroup بيقلب بين شاشات تانية بدون تركيز على الفرص الذهبية.
6. **شاشة الأسهم (`#stocks`):** جدول ميت بدون لوجوهات، وبدون فرز للأعمدة، وسبارك لاين ملوش علاقة بحركة الـ 7 أيام الفعلية.
7. **جريمة إخفاء التقارير:** قصيتوا التقارير من شاشة التوقعات ورمتوها في الشارع ونسيتوا تحطوها في القائمة العلوية (`nav-config.ts`).

* **النتيجة المطلوبة:** فتح `#trading-chart` يظهر شارت الشموع اليابانية التفاعلي ومؤشرات الـ SMA و RSI بالكامل مع **0 أخطاء في الكونسول**.

### النقطة 2: إحياء رادار السيولة الميت وإلغاء حجب الأسهم (Liquidity Radar Table)
* **الملف:** `src/components/shared/LiquidityRadarView.tsx`
* **السطور:** 301-323 و 545-560
* **المشكلة:**
  1. فلتر `hideInactive` (مفعل افتراضياً) يفحص `s.whale.net_flow_egp` و `s.volume`، وكلاهما `undefined` في رد الـ API الجديد، فيقوم بمسح كل الأسهم وإظهار "لا توجد أسهم مطابقة".
  2. تابات الفرز تفحص `st.phase` بينما بايثون يرسل `classification`.
* **الخطة:**
  1. تعديل فلتر `hideInactive` ليفحص السيولة الحقيقية:
     ```typescript
     if (hideInactive) {
       out = out.filter((s) => {
         const turnover = Number(s.turnover_egp ?? s.volume ?? 0);
         return turnover >= 1_500_000;
       });
     }
     ```
  2. ربط الـ `BUCKET_FILTERS` بحقل `classification`:
     * `all` -> الكل
     * `DRY_ACCUMULATION` -> تجميع هادئ / جفاف
     * `ACCUMULATION_CONFIRMED` -> تدفق حيتان / اختراق
     * `DISTRIBUTION_RISK` -> خطر تصريف / قمة
     * `ILLIQUID_TRAP` -> مصيدة سيولة
  3. تحديث أعمدة الجدول لتعرض:
     `السهم | السعر | RVOL | قيمة التداول (Turnover) | مدى الحركة (ATR) | تصنيف الحيتان | فحص السهم`.
* **النتيجة المطلوبة:** فتح `#liquidity-radar` يعرض جدول الـ 10 أسهم بالكامل مع تلوين الحالات وشارات الحيتان واختفاء رسالة "لا توجد أسهم مطابقة".

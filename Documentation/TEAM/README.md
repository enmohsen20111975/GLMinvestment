## ترتيب أولوية المراجع

1. توجيه صريح حديث من المالك، ضمن حدود الأمان وحماية الإنتاج.
2. دستور المشروع المعتمد في `Documentation/MASTER_REFERENCE/01-CONSTITUTION_AND_ARCHITECTURE.md`.
3. قواعد الأمن والحوكمة في `Documentation/MASTER_REFERENCE/04-SECURITY_AND_GOVERNANCE.md`.
4. تعليمات الدور في هذا المجلد.
5. ملف تسليم الجلسة أو worklog أو التقارير التاريخية.

عند التعارض، لا تختَر بصمت. سجّل التعارض، واذكر الملفات/الأسطر والأثر، ثم اطلب قرارًا من المالك إذا كان التعارض يغيّر صلاحيات أو مخاطرة أو سلوكًا إنتاجيًا.

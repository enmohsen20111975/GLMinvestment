## 2. القواعد الأساسية

### Rule 1: NO-FAKE-DATA
أي بيانات غير متاحة → `null` أو "غير متاح". ممنوع اختلاق أسعار أو مستويات.

### Rule 2: PYTHON = BRAIN
كل الحسابات في Python backend. Next.js = DISPLAY ONLY.

### Rule 3: SINGLE-DISPLAY-SOURCE
كل توصية في الواجهة لازم ترجع لنفس مصدر القرار.

### Rule 4: NO-DUPLICATION
ممنوع تكرار نفس المنطق في ملفين. استخدم المكونات الموحدة.

### Rule 5: CLIENT-FACING-STYLE
كل النصوص للمستخدم بالعربية. الأخطاء الإنجليزية ممنوعة.

### Rule 6: GIT-PUSH-DISCIPLINE
كل مهمة منتهية → commit + push. مفيش شغل بدون تسليم.

### Rule 7: NO-DESTRUCTIVE-OPERATIONS
ممنوع `reset --hard` أو `force-push` على main بدون موافقة المالك.

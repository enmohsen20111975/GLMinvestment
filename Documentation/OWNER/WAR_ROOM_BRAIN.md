**تاريخ التحديث الصارم:** 15 أكتوبر 2026 — الساعة 13:55 بتوقيت القاهرة  
**الشركاء والقادة:**  
- **المهندس محسن:** المالك ورئيس مجلس الإدارة وصاحب القرار النهائي.  
- **جيمي (Jimmy):** المدير العام والشريك (51%)، كبير المهندسين والمعماريين ورئيس الرقابة الكمية.

بناء وتشغيل **أقوى منصة استثمارية وكمية متكاملة في الشرق الأوسط (GLMinvestment / invist.m2y.net)**:
- **تغطي 7 أسواق:** البورصة المصرية (EGX)، تداول السعودية (TADAWUL)، بورصة الكويت (KSE)، بورصة قطر (QSE)، الأسهم الأمريكية (US)، العملات الرقمية (Crypto)، والذهب والمعادن (Gold).

- **نموذج الربحية:** فترة تجربة 3 أيام ➔ اشتراكات مدفوعة (Instapay / بطاقات) ➔ محتوى وتنبيهات حصرية على تليجرام وإشعارات المتصفح في الساعات الذهبية للتداول.

### تقسيم المهام الصارم بدون تداخل:
1. **ALPHA (9 مبرمجين):**
   - مسؤولون عن الشاشات وواجهات المستخدم ومكونات React/Next.js في `src/`.
   - مرجعيتهم الحصرية: تصاميم Google Stitch في `stitch_full_website_ui_design/`.
   - استخدام الـ `UnifiedTable` ومكونات التصميم الموحدة، وحظر تام لأي ألوان هاردكود أو حسابات محلية داخل الواجهة.
2. **BRAVO (9 مبرمجين):**
   - مسؤولون عن خوارزميات التداول، الرادار، كشف السكين الساقط، إدارة المخاطر R/R، ماكينة إشعارات الحيتان التسويقية، وجدولة الكرون.

3. **SOSO (9 مبرمجين):**
   - مسؤولة عن جلب البيانات، الاسكرابرات عبر REST و TradingView، سحب القوائم المالية، تنظيف الجداول من الهيدرات الفاسدة، وضمان سلامة `data_engine.db`.
   - ملعبها: `data_engine/` فقط.
4. **كيلو كود (Kilo Code / Local Agent):**
   - الذراع التنفيذي الميداني: فحص البيلد، تشغيل بيئات WSL، فحص PM2، والتحقق المستقل من سلامة Git بدون force push.

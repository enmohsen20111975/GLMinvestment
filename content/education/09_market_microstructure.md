# درس 9: بنية السوق والسيولة المؤسسية (Market Microstructure)

> **المستوى:** متقدم جداً | **الوقت:** 32 دقيقة | **الجمهور المستهدف:** المتداول المؤسسي + المحلل الكمي

---

## 1. الأساس العلمي والنظري

### 1.1 ليه "السعر بيتحرّك" مش سؤال بسيط

السعر بيتحرّك لما فيه **imbalance** بين العرض والطلب. بس **إزاي** بيحصل الـ imbalance ده؟

الجواب: في **3 طبقات** بيتحرك فيها السعر:

1. **Macroeconomic flows:** قرار فائدة / بيانات اقتصاد → يدخل سيولة كبيرة
2. **Institutional order flow:** صناديق بتفتح/تقفل positions → حركات كبيرة
3. **Microstructure:** الـ order book + spread + depth → الحركة الفورية

### 1.2 دفتر الأوامر (Order Book)

```
┌──────────────────────────────────────────────────────────────────────┐
│                    Order Book (دفتر الأوامر)                         │
│                                                                      │
│   ┌──────────────────────┐  السعر  ┌──────────────────────┐         │
│   │   Bids (أوامر شراء)   │         │  Asks (أوامر بيع)    │         │
│   ├──────────────────────┼─────────┼──────────────────────┤         │
│   │  2000 سهم @ 99.5ج    │  99.5   │  1000 سهم @ 100.5ج   │         │
│   │  1200 سهم @ 99.0ج    │  99.0   │   800 سهم @ 101.0ج   │         │
│   │  2000 سهم @ 98.5ج    │  98.5   │  1500 سهم @ 101.5ج   │         │
│   │   500 سهم @ 98.0ج    │  98.0   │  2000 سهم @ 102.0ج   │         │
│   └──────────────────────┴─────────┴──────────────────────┘         │
│                                                                      │
│   ┌─ Spread ────────────────────────┐                              │
│   │  الفرق بين أعلى Bid (99.5)      │                              │
│   │  وأقل Ask (100.5) = 1.0 جنيه    │                              │
│   └─────────────────────────────────┘                              │
│                                                                      │
│   ═══ Imbalance = (5200 - 5300) / (5200+5300) = -0.01 (محايد)      │
│                                                                      │
│   Imbalance > +0.5 = طلب ضخم (STRONG BUY)                           │
│   Imbalance < -0.5 = عرض ضخم (STRONG SELL)                          │
└──────────────────────────────────────────────────────────────────────┘
```

الـ order book = قائمة كل أوامر الـ **limit** المعلّقة:

| الـ Bid (شراء) | السعر | الـ Ask (بيع) |
|----------------|------|---------------|
| 500 سهم @ 99.5 | 99.5 | 1000 سهم @ 100.5 |
| 1200 سهم @ 99.0 | 99.0 | 800 سهم @ 101.0 |
| 2000 سهم @ 98.5 | 98.5 | 1500 سهم @ 101.5 |

**الـ Spread:** الفرق بين أعلى bid وأقل ask (0.5 جنيه في المثال)
**الـ Depth:** حجم الأوامر عند كل مستوى سعر

### 1.3 أنواع الأوامر (Order Types)

| النوع | الوصف | الاستخدام |
|------|------|---------|
| **Market Order** | تنفيذ فوري بأفضل سعر متاح | عند الحاجة للسرعة |
| **Limit Order** | تنفيذ عند سعر محدد أو أحسن | للتحكّم في السعر |
| **Stop Order** | يتحوّل لـ market عند سعر معيّن | وقف الخسارة |
| **Iceberg Order** | جزء صغير ظاهر، الباقي مخفي | للأوامر الكبيرة |
| **VWAP Order** | تنفيذ تدريجي على مدار اليوم | للمؤسسات |

### 1.4 دور صانع السوق (Market Maker)

صانع السوق بيوفّر **سيولة فورية** بوضع أوامر limit على الجانبين (bid + ask).

**كيف بيربح؟**
1. **Spread capture:** بيشتري عند bid، يبيع عند ask (الـ spread ده ربحه)
2. **Inventory rebalancing:** بيمسك inventory ويبيع/يشتري ليعادله

**مخاطر صانع السوق:**
- **Adverse selection:** لما الـ informed traders (اللي عندهم معلومات) يبيعوا، الـ MM بيشتري ويخسر
- **Inventory risk:** لو السعر اتحرّك ضد inventory الـ MM

### 1.5 صفقات الحجم الكبير (Block Trades)

المؤسسات الكبيرة مش بتدخل بـ market order (هيحرّك السعر ضدها). بتستخدم:

1. **Dark pools:** شبكات بديلة بتطابق الأوامر الكبيرة بدون ظهور في الـ order book
2. **Block trade negotiation:** بيع/شراء مباشر بين طرفين
3. **Algorithmic execution:** تقسيم الأمر على مدار اليوم/الأسبوع (TWAP/VWAP)

## 2. متى ولماذا تفشل الأداة؟ (Failure Mode)

### 2.1 فشل قراءة الـ Order Book

1. **Spoofing:** أوامر وهمية بيتحطّت عشان تخلق انطباع بوجود سيولة → تتلغى قبل التنفيذ
2. **Layering:** أوامر متعدّدة على مستويات مختلفة عشان تخلق وهم الـ depth
3. **النتيجة:** قراءة الـ order book من غير تأكيد التنفيذ = قراءة مش vortex

### 2.2 فشل رصد الـ Order Flow

- **False signal:** حركة كبيرة على volume ممكن تكون بسبب صفقة واحدة مش استمرارية
- **Latency:** الـ HFT (High Frequency Trading) بيستفيد من فروقات أجزاء الثانية — المستخدم العادي مش هيقدر

## 3. دراسة حالة من السوق الواقعي

### حالة: تجميع مؤسسي في سهم EGX

**السيناريو:** مؤسسة عايزة تشتري 1M سهم من سهم معيّن بس مينفعش تدخل دفعة واحدة.

**التكتيك:**
1. **Iceberg orders:** تحط أمر limit 10K سهم ظاهر + 990K مخفي
2. **VWAP execution:** تنفّذ تدريجياً على مدار اليوم بسعر ≤ VWAP
3. **Cross orders:** تتوافق مع طرف تاني على بيع مباشر (block trade)

**إزاي ترصد ده (كمتداول عادي):**
1. **Volume spike بدون حركة سعر كبيرة:** فوليوم عالي بس السعر ماتحرّكش كتير = امتصاص
2. **Bid/ask imbalance:** الـ asks بتقل، الـ bids بتزيد = تجميع
3. **Closing auctions:** الفوليوم بيزيد في آخر 15 دقيقة من الجلسة

### حالة: Spoofing في الـ Order Book

**السيناريو:** متلاعب يحط أمر بيع ضخم عند 105 (سعر فوق السعر الحالي بـ 3%)

**الهدف:** يخلق انطباع إن فيه ضغط بيعي → المستخدمين الذعر → السعر ينزل → المتلاعب يشتري أرخص

**إزاي تكشفه:**
- الأمر اتلغى فجأة قبل ما السعر يوصله
- الـ volume الحقيقي على مستوى 105 كان صفر (المنطقة نفذ فيها spoofing)

## 4. التطبيقات العملية (Practical Playbook)

### 4.1 📊 مثال عملي: قراءة الـ Order Book لسهم EGX

> افتح شاشة الـ Order Book (Level 2) على منصتك. هتشوف جدول زي ده:

| الـ Bid (أوامر شراء) | السعر | الـ Ask (أوامر بيع) |
|---|---|---|
| 2,000 سهم @ 99.5 ج | **99.5** | 1,000 سهم @ 100.5 ج |
| 1,200 سهم @ 99.0 ج | **99.0** | 800 سهم @ 101.0 ج |
| 2,000 سهم @ 98.5 ج | **98.5** | 1,500 سهم @ 101.5 ج |
| 500 سهم @ 98.0 ج | **98.0** | 2,000 سهم @ 102.0 ج |

**التحليل العملي:**

| المقياس | الحساب | التفسير |
|---|---|---|
| **الـ Spread** | أعلى Bid (99.5) − أقل Ask (100.5) = 1.0 ج | السبريد عالي — السهم قليل السيولة مؤقتاً |
| **إجمالي الـ Bids** | 2,000 + 1,200 + 2,000 + 500 = 5,700 سهم | الطلب الإجمالي |
| **إجمالي الـ Asks** | 1,000 + 800 + 1,500 + 2,000 = 5,300 سهم | العرض الإجمالي |
| **الـ Imbalance** | (5,700 − 5,300) ÷ (5,700 + 5,300) = +0.04 | محايد تقريباً (+4%) |
| **التوقّع** | انتظر | لا إشارة قوية للشراء أو البيع |

**القاعدة العملية:**
- Imbalance > +0.5 (50%+) → 🟢 **STRONG BUY** — طلب ضخم
- Imbalance > +0.2 → شراء محتمل
- Imbalance بين -0.2 و +0.2 → محايد
- Imbalance < -0.2 → بيع محتمل
- Imbalance < -0.5 → 🔴 **STRONG SELL** — عرض ضخم

### 4.2 ✅ قائمة كشف Spoofing (التلاعب)

> الـ Spoofing = أوامر وهمية بيتحطّت عشان تخلق انطباع بسيولة. اتخلص منها قبل ما تأخذ قرار.

| # | السؤال | إجابتي | تم؟ |
|---|---|---|---|
| 1 | الأمر الكبير اتحطّ فجأة (مش متراكم)؟ | _________ | ☐ |
| 2 | سعر الأمر بعيد عن السعر الحالي (> 2%)؟ | _________ | ☐ |
| 3 | الأمر بيتلغى قبل ما يتنفّذ؟ | _________ | ☐ |
| 4 | مفيش تنفيذ فعلي على مستوى سعر الأمر؟ | _________ | ☐ |
| 5 | الأمر ظهر ثم اختفى بعد ثواني؟ | _________ | ☐ |

> 🚨 لو 3+ إجابات "نعم" → الأمر وهمي (Spoofing). ما تعتمدش عليه في قرارك.

### 4.3 📈 مثال عملي: كشف الامتصاص المؤسسي (Absorption)

> **السيناريو:** سهم COMI — الفوليوم في آخر 15 دقيقة = 500,000 سهم (3× المتوسط)، بس السعر ماتحرّكش.

| المقياس | القيمة | التفسير |
|---|---|---|
| الفوليوم (آخر 15 دقيقة) | 500,000 سهم | عالي جداً |
| متوسط الفوليوم (نفس الفترة) | 150,000 سهم | 3× المتوسط |
| تغيّر السعر في نفس الفترة | -0.1% (تقريباً ثابت) | ⚠️ صفر حركة رغم الفوليوم |
| **التفسير** | امتصاص مؤسسي قوي | 🟢 المؤسسات بتشتري بدون ما ترفع السعر |

**ماذا يعني هذا للمستثمر؟**
- 🟢 إشارة شراء قوية — المؤسسات بتشتري بصمت
- ⚠️ استنى تأكيد إضافي (شمعة شراء + اختراق مقاومة)
- 🎯 الهدف: متابعة السهم 2-3 أيام، لو طلع بفوليوم مستمر = دخول

### 4.4 📓 قالب مراقبة الـ Order Flow اليومي

> اطبّع القالب ده واملأه نهاية كل جلسة تداول (15 دقيقة قبل الإغلاق).

| السهم: __________ | التاريخ: __/__/____ |
|---|---|

| المؤشر | القيمة | التوقّع |
|---|---|---|
| الـ Spread (الفرق بين Bid و Ask) | _______ ج | < 0.5% = سيولة كويسة |
| Imbalance (Bids vs Asks) | _______ | >+0.5 شراء، <-0.5 بيع |
| Volume آخر ساعة | _______ | مقارنة بالمتوسط |
| Volume آخر 15 دقيقة (Closing Auction) | _______ | زيادة = تأكيد صفقة كبيرة |
| تغيّر السعر آخر ساعة | _______ % | ثابت + فوليوم عالي = امتصاص |
| Block Trades (لو متاح) | _______ | حجم + سعر |
| خلاصة اليوم | _______ | _________ |

**القاعدة العملية:** الفوليوم العالي + السعر الثابت = امتصاص. الفوليوم العالي + السعر النازل = بيع مؤسسي حقيقي. الفرق يحدد قرارك.

## 5. قائمة فحص تنفيذية

### ✅ قراءة الـ Order Book
- [ ] بتشوف الـ imbalance (bid vs ask volume)؟
- [ ] بتأكّد إن الأوامر حقيقية (مش spoofing)؟
- [ ] بتتابع الـ depth (مش بس الـ top of book)؟

### ✅ رصد الـ Order Flow
- [ ] بتراقب الـ volume spikes بدون حركة سعر = امتصاص؟
- [ ] بتفرّق بين block trade واحد vs استمرارية؟
- [ ] بتشوف closing auction volume (آخر 15 دقيقة)؟

### ✅ حماية من التلاعب
- [ ] متعتمدش على spoofing layer في الـ order book
- [ ] بتأكّد التنفيذ الفعلي قبل ما تعتبر السيولة حقيقية
- [ ] بتستخدم VWAP كـ reference (مش last price)

## 🎯 الملخص التنفيذي — اللي هتعمله من بكرة

1. **افتح شاشة Level 2 (Order Book)** لـ CIB أو COMI — احسب Imbalance لـ 5 مستويات Top: (Bids − Asks) ÷ (Bids + Asks). لو > +0.3 = إشارة شراء، < -0.3 = إشارة بيع.
2. **راجع آخر 15 دقيقة من كل جلسة تداول** — لو الفوليوم زاد 2×+ والسعر ثابت → امتصاص مؤسسي = إشارة شراء.
3. **ما تعتمدش على أوامر كبيرة بعيدة عن السعر الحالي** — غالباً spoofing. شوف التنفيذ الفعلي قبل ما تقرر.
4. **قارن الـ Spread على نفس السهم على مدار الأسبوع** — لو زاد، السهم بيفقد سيولة = إشارة خطر.
5. **راقب Closing Auction (آخر 15 دقيقة)** — المؤسسات بتنفّذ أكبر أوامرها هنا. لو الفوليوم في آخر 15 دقيقة = 40%+ من حجم اليوم = فيه قرار مؤسسي كبير.

> 💡 **القاعدة الذهبية:** السعر اللي بتشوفه على الشارت = نتاج المزاد. الـ Order Book = مكان المزاد. اللي بيراقب المزاد بيستبق السعر. اللي بيستنى السعر بيكون آخر واحد بيدخل.

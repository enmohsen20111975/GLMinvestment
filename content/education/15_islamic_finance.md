# درس 15: التمويل الإسلامي والتطهير — من المبادئ إلى التطبيق العملي في التداول

> **المستوى:** متقدم | **الوقت:** 32 دقيقة | **الجمهور المستهدف:** المستثمر المسلم + المتداول الشرعي

---

## 1. الأساس العلمي والنظري

### 1.1 ليه "الأسهم حلال" مش كفاية

كثير من المستثمرين المسلمين يكتفون بسؤال "هل السهم حلال؟" — هذا سؤال **بدائي**. السؤال الصحيح:

1. ما **منهجية** الفتوى؟ (AAOIFI / MSCI / S&P / Musaffa / إسلامك / درهم)
2. ما **نسبة التطهير المطلوبة** من أرباح هذا السهم؟
3. هل أرباح الشركة من **أنشطة غير مباشرة** (إيجار من بنوك ربوية، فوائد على الفائض النقدي)؟
4. كيف **أطبّق التطهير فعلياً** في دورة الاستثمار السنوية؟
5. ما الفرق بين التطهير **للأرباح الرأسمالية** و **للتوزيعات النقدية**؟

### 1.2 المحظورات الشرعية الثلاثة (3 Principles)

التمويل الإسلامي مبني على تجنب **3 محظورات أساسية**:

```
┌──────────────────────────────────────────────────────────────────────┐
│                  المحظورات الشرعية الثلاثة                              │
│                                                                      │
│   1. الربا (Usury / Interest)                                        │
│      ─────────────────────────────                                    │
│      • الزيادة المقررة على دين مؤجل                                  │
│      • القرض بفائدة (أي فائدة مشروطة)                                │
│      • بيع النقود بالنقود بأجل بفائدة                                │
│      → النص: "أحل الله البيع وحرم الربا" (البقرة 275)                │
│                                                                      │
│   2. الغرر (Excessive Uncertainty / Speculation)                    │
│      ─────────────────────────────                                    │
│      • بيع ما لا تملك (short selling على نقد)                        │
│      • بيع شيء غير موجود أو غير محدد                                │
│      • المقامرة (الفوركس عالي الرافعة بدون تسليم)                    │
│      → النص: "نهى النبي عن بيع الغرر" (صحيح مسلم)                    │
│                                                                      │
│   3. الميسر (Gambling / Qimar)                                      │
│      ─────────────────────────────                                    │
│      • العقود التي فيها رهان خالص                                   │
│      • الخيارات الثنائية (Binary Options)                            │
│      • العقود الاشتقاقية بدون تسليم فعلي                            │
│      → النص: "إنما الخمر والميسر... رجس" (المائدة 90)               │
└──────────────────────────────────────────────────────────────────────┘
```

### 1.3 معايير الفرز الشرعي (Stock Screening)

كل هيئة شرعية ليها معايير، لكن **المعايير الـ 5 الرئيسية** مشتركة:

| المعيار | حد AAOIFI | حد MSCI | حد S&P |
|---------|----------|---------|--------|
| **1. الدين الربوي / إجمالي الأصول** | ≤ 30% | ≤ 33% | ≤ 33% |
| **2. السيولة النقدية + الاستثمارات الربوية / إجمالي الأصول** | ≤ 30% | ≤ 33% | ≤ 49% |
| **3. الذمم المدينة / إجمالي الأصول** | ≤ 70% | ≤ 49% | ≤ 49% |
| **4. مجموع الديون + السيولة / رأس المال السوقي** | ≤ 33% | ≤ 33% | ≤ 33% |
| **5. إيرادات غير مباحة / إجمالي الإيرادات** | ≤ 5% | ≤ 5% | ≤ 5% |

**ملاحظة:** AAOIFI أكثر صرامة من MSCI و S&P. الأسهم المتوافقة مع AAOIFI غالباً متوافقة مع الأخرى لكن ليس العكس.

### 1.4 القطاعات المحظورة قطعاً (Hard Exclusions)

```
القطاعات المحظورة في كل المنهجيات:
┌────────────────────────────────────────────────────────────────┐
│  ❌ البنوك التقليدية (Conventional Banking)                    │
│  ❌ التأمين التقليدي (Conventional Insurance)                  │
│  ❌ المنتجات الغذائية المحرمة (Pork, Alcohol)                  │
│  ❌ الترفيه المثير (Casinos, Gambling, Adult)                 │
│  ❌ الإعلام غير الأخلاقي                                       │
│  ❌ الأسلحة غير المشروعة                                       │
│  ❌ استنساخ البشر / أبحاث الجينات المثيرة للجدل                │
└────────────────────────────────────────────────────────────────┘

القطاعات الجائزة (Permitted):
  ✅ الصناعة التحويلية       ✅ التقنية           ✅ العقار (غير مراباة)
  ✅ السلع الاستهلاكية       ✅ الرعاية الصحية     ✅ الطاقة (مع فحص)
  ✅ البنوك الإسلامية        ✅ التأمين التكافلي   ✅ التعدين
```

## 2. آلية التطهير (Purification Mechanism)

### 2.1 مفهوم التطهير

التطهير = **إخراج الجزء غير المباح من الأرباح** وتوزيعه على **جهات برّ** (ليس كصدقة، بل كـ "إخراج لما ليس لي").

### 2.2 معادلة التطهير القياسية

```
┌──────────────────────────────────────────────────────────────────────┐
│              معادلة التطهير الكاملة (Purification)                    │
│                                                                      │
│  التطهير الإجمالي = تطهير التوزيعات + تطهير الأرباح الرأسمالية       │
│                                                                      │
│  أ) تطهير التوزيعات النقدية:                                          │
│     التوزيع = (نسبة الإيراد غير المباح) × (إجمالي التوزيع المستلم)   │
│                                                                      │
│     مثال: سهم COMI                                                   │
│     - توزيع 1.5 ج.م/سهم                                              │
│     - نسبة الإيراد غير المباح = 3% (فوائد على فائض نقدي)             │
│     - تطهير = 0.03 × 1.5 = 0.045 ج.م/سهم                            │
│     - لـ 1000 سهم: 45 ج.م تُخرَج                                    │
│                                                                      │
│  ب) تطهير الأرباح الرأسمالية:                                         │
│     التطهير = (نسبة الإيراد غير المباح) × (الربح الرأسمالي)          │
│                                                                      │
│     مثال:                                                            │
│     - شراء 1000 سهم COMI @ 18.50                                     │
│     - بيع @ 22.00 → ربح 3,500 ج.م                                   │
│     - نسبة الإيراد غير المباح = 3%                                  │
│     - تطهير = 0.03 × 3,500 = 105 ج.م                                │
│                                                                      │
│  الإجمالي للسنة = 45 + 105 = 150 ج.م تُخرَج                          │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.3 طريقة حساب نسبة الإيراد غير المباح

```
نسبة الإيراد غير المباح = 
  (إجمالي الإيرادات غير المباحة) / (إجمالي الإيرادات)

حيث تشمل الإيرادات غير المباحة:
  • الفوائد على الودائع البنكية (للفائض النقدي)
  • إيرادات من شركات تابعة محرّمة (مثلاً: مصنع أغذية مع كازينو فرعي)
  • إيرادات من بيع منتجات محرّمة (للأنشطة المختلطة)

المصدر: القوائم المالية السنوية (Income Statement) — بند:
  "Other Income" + "Interest Income" (إن وجد)
```

### 2.4 متى يجب التطهير؟

| الحالة | هل يجب التطهير؟ | السبب |
|-------|-----------------|------|
| سهم متوافق شرعياً، استلمت توزيعات | ✅ نعم | لاستلام جزء من الإيراد غير المباح |
| سهم متوافق شرعياً، بعت بربح | ✅ نعم | رأس المال نما بفضل أنشطة مختلطة |
| سهم متوافق شرعياً، بعت بخسارة | ❌ لا | لا ربح لتطهيرها |
| سهم غير متوافق شرعياً (محرّم) | ❌ لا تطهير، بل **توبة** | بيعه فوراً، التزاماً بالضوابط |
| توزيعات مؤجلة (لم تستلم بعد) | ❌ حتى الاستلام | التطهير عند الاستلام فعلياً |

## 4. أخطاء شائعة في التطهير

### 4.1 الأخطاء الفنية

| الخطأ | العلاج |
|-------|------|
| **عدم التطهير بحجة "النسبة ضئيلة"** | حتى 0.5% تطهّر — قاعدة الورع |
| **تطهير نفس الربح مرتين** | سجّل كل عملية تطهير في سجل مستقل |
| **استخدام نسبة قديمة** | استخدم أحدث قائمة مالية سنوية |
| **إخراج التطهير كصدقة عادية** | يُخرج لجهات البرّ بقصد التطهير (نية محددة) |
| **احتساب الربح الرأسمالي قبل البيع** | التطهير عند تحقق الربح فعلياً (البيع) |
| **عدم تطهير التوزيع المؤجَّل** | عند الاستلام الفعلي، طهّر فوراً |

### 4.2 الأخطاء المفاهيمية

- **"السهم حلال" ≠ لا يحتاج تطهير** — حتى الأسهم المتوافقة تحتاج تطهير (النسبة < 5%).
- **التطهير ≠ زكاة** — التطهير إخراج مال غير شرعي، الزكاة عبادة مالية.
- **البيع المكشوف (Short Selling) كله محرّم** — لأنه بيع ما لا تملك (غرر). إلا الصيغة المعدّلة (Salam).
- **الفوركس بالرافعة المالية مرتفعة** = ميسر. الرافعة العالية تجعل الصفقة قمار.
- **العقود الاشتقاقية (Options/Futures)** = غالباً محرّمة (غرر + ميسر) إلا في حالات نادرة للتحوّط الفعلي.

### 5.2 متى يتم الإخراج؟

```
- التوزيعات: عند الاستلام الفعلي للنقد في حساب التداول
- الأرباح الرأسمالية: عند إغلاق الصفقة (بيع السهم)
- يفضل الإخراج شهرياً أو ربع سنوياً (تراكمي)
- لا تتركها لآخر السنة — قد تنسى أو تختلط
```

## 6. التداول اليومي واليوم (Day/Swing Trading) من منظور شرعي

### 6.1 التداول اليومي (Day Trading)

```
الأصل: جائز إذا التزمت بالضوابط:
  ✓ السهم متوافق شرعياً (تطهير الربح)
  ✓ لا بيع مكشوف (no short selling)
  ✓ لا فوركس بزوج عملات بدون تسليم
  ✓ لا عقود آجلة على أسهم
  ✓ لا خيارات (options) على أسهم فردية

⚠️ تنبيه: التداول اليومي المفرط قد يُشبه الميسر إذا:
  - كان القصد المضاربة على إشارات تقنية فقط (بدون تحليل أساسي)
  - كانت الرافعة عالية بشكل يجعل الخسارة شبه مؤكدة
  - كان التردد مرتفعاً جداً (عشرات الصفقات/يوم)
```

### 6.2 التأجير (Tawarruq) — نقطة خلاف

بعض البنوك الإسلامية تستخدم التأجير المنظم (Commodity Murabaha) لتمويل شخصي. **خلاف فقهي:**

- **مجمع الفقه الإسلامي الدولي:** جائز بشرط وجود سلعة حقيقية
- **بعض العلماء المعاصرين:** محرّم لأنه التفاف على الربا

**القاعدة العملية:** تجنّب المنتجات المالية المعقّدة جداً — التمسك بالبسيط الواضح.

## 7. النقاط الرئيسية

1. **التوافق الشرعي ليس نعم/لا** — هناك مستويات (AAOIFI أصرم من MSCI من S&P).
2. **التطهير إلزامي حتى للأسهم المتوافقة** — لأن نسبة < 5% من الإيراد غير مباحة.
3. **المعادلة بسيطة:** (نسبة الإيراد غير المباح) × (التوزيعات + الأرباح الرأسمالية).
4. **الإخراج عند الاستلام فعلياً** — لا قبل ولا بعد بمدة طويلة.
5. **دفتر تطهير سنوي إلزامي** — لا تتركها للذاكرة.
6. **القطاعات المحظورة قطعاً:** بنوك تقليدية، تأمين تقليدي، كحول، قمار، أسلحة غير مشروعة.
7. **التطهير ≠ الزكاة** — التطهير إخراج، الزكاة عبادة مستقلة بنصاب وحول.
8. **تجنّب:** البيع المكشوف، العقود الاشتقاقية على أسهم فردية، الفوركس ذو الرافعة العالية.

---

## 🎯 الملخص التنفيذي — اللي هتعمله من بكرة

1. **افتح دفتر تطهير سنوي** (قالب في القسم 5.1) — ابدأ من أول توزيعات قادمة تستلمها.
2. **راجع كل سهم في محفظتك** على معايير الفرز الخمسة (ديون / سيولة ربوية / ذمم / مجموع الديون / إيرادات غير مباحة) — شيل أي سهم مش بيطابق.
3. **احسب نسبة الإيراد غير المباح** لكل سهم متوافق — استخدم آخر قائمة مالية سنوية.
4. **طبّه فوراً عند استلام التوزيعات** — لا تؤجل. سجّل في الدفتر + أخرج لجهة برّ موثوقة.
5. **ما تستخدمش البيع المكشوف** ولا العقود الاشتقاقية على أسهم فردية — كلها غرر/ميسر. لو محتاج تحوّط، استخدم الصكوك الإسلامية.

> 💡 **القاعدة الذهبية:** الورع في الشبهات خير من اقتحامها. تطهير سهم متوافق بنسبة 1% أفضل ألف مرة من تجاهله بحجة "ضئيل". المبالغ الصغيرة المتراكمة تتحول إلى مبالغ كبيرة في حسناتك يوم القيامة. التطهير مش عبء — هو طهارة مالك وضميرك.

## 8. خلاصة تنفيذية

التمويل الإسلامي مش مجرد "قائمة أسهم حلال" — هو **منهجية فقهية كاملة** تشمل:
- الفرز وفق 5 معايير كمية
- حساب دقيق لنسبة الإيراد غير المباح
- تطهير دوري للتوزيعات والأرباح الرأسمالية
- دفتر تطهير سنوي منظم
- إخراج فعلي لجهات برّ موثوقة

المنصة توفر **8 مصادر فتوى** وتدمجها في حاسبة تطهير تلقائية عبر `/api/sharia/purification`، لكن المستثمر يبقى مسؤولاً عن:
1. مراجعة شهرياً للتوزيعات المستلمة
2. تطهير فوري عند البيع بربح
3. الإخراج الفعلي لجهة برّ (لا يكفي الحساب النظري)

> **القاعدة الذهبية:** "الورع في الشبهات خير من اقتحامها." — تطهير سهم متوافق بنسبة 1% أفضل ألف مرة من تجاهله بحجة "ضئيل". المبالغ الصغيرة المتراكمة تتحول إلى مبالغ كبيرة في حسناتك يوم القيامة.
